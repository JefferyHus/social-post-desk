# Contributing

Bug reports, feature ideas and pull requests are welcome. For a bug report, include the steps to reproduce it, what you expected and your Node.js version. Use sample projects and fictional data in issues, screenshots and test fixtures.

1. Use a maintained release of Node.js 24 or later.
2. Run `npm test` to check the server, store and client helpers.
3. Run `npm run demo` and open [the demo](http://127.0.0.1:3010) to try the workspace with simulated LinkedIn publishing. The demo password is `social-desk-demo`.
4. Open a pull request with a short description and the checks you ran.

See [SECURITY.md](SECURITY.md) for private security reports.
